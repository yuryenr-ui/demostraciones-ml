# Demostraciones de Machine Learning

Libro (Jupyter Book 2) con las demostraciones de K-NN, Ridge, Lasso, árboles de decisión y AdaBoost del curso de
Machine Learning (Universidad del Norte, Prof. Lihki Rubio Ortega). Autor: Yuryen Rollo.

- Los capítulos con código se escriben en `fuentes/*.py` (formato de celdas `# %%`), se convierten a `.ipynb` y se
  ejecutan con `jupyter nbconvert --execute`. GitHub Actions publica el libro en GitHub Pages en cada push a `main`.
